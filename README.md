# Aula Clara · Demostración

[Abrir demostración](https://framosr5-del.github.io/Demostraci-n-Aura-Clara/)

Prototipo escolar con datos totalmente ficticios. Selecciona **Docente**, **Dirección** o **Familia** para explorar las pantallas desde computadora o celular.

Los cambios permanecen únicamente durante la sesión; al recargar o cambiar de rol se restablecen los ejemplos. No se requiere cuenta ni instalación. No contiene conexión a Supabase, credenciales ni datos escolares reales.

Este repositorio aloja los archivos compilados de la demostración. GitHub Pages publica la rama **main**, carpeta **/(root)**. El código fuente y las migraciones de la plataforma se entregan por separado.

Esta demostración no está certificada para producción ni para registrar información real.
